# Happy Birthday Website for Shehnaz ❤️

GitHub Pages-e live host korar jonno eita ready project.

## 🖼️ Picture kivabe change korben?
1. Eikhane `profile.jpg` name ekta file ache.
2. Apnar pochonder chobi-tar naam badle `profile.jpg` korun ebong eikhane replace kore din.
3. Otoba `index.html` file khule `<img src="profile.jpg" ...>` line e apnar image er link ba naam boshate paren.

## 🚀 GitHub Pages e upload & live korar niyam:
1. GitHub-e giye ekta **New Repository** create korun (e.g. `birthday-surprise`).
2. Ei zip file extract kore shobgulo file (`index.html`, `profile.jpg`, `README.md`) oi repository-te upload korun ebong **Commit changes** korun.
3. Repository er **Settings** > **Pages** e jaan.
4. **Branch** hishebe `main` (ba `master`) select kore **Save** korun.
5. 1-2 minute por apnar website-er live link ready hoye jabe!
